# Model hapus latar produk

`u2netp.onnx` — U²-Net (versi kecil "u2netp") untuk memisahkan objek utama dari latar.
Dipakai Basecamp → Katalog → Studio Promo, dijalankan di browser lewat onnxruntime-web.

- Sumber: https://github.com/xuebinqin/U-2-Net (Xuebin Qin dkk.), lisensi Apache License 2.0.
- Berkas ONNX diambil dari rilis rembg (https://github.com/danielgatis/rembg, lisensi MIT).
